# Структура презентации к защите

Ориентир — 15–16 слайдов, минимум текста, максимум скриншотов реально работающей системы (см. список в `13-figures.md`). Ниже — что должно быть на каждом слайде, не готовый текст для копирования.

1. **Титульный слайд** — тема, автор, руководитель, институт
2. **Актуальность** — проблема ручного/разрозненного учёта (1–2 тезиса, без воды)
3. **Цель и задачи** — цель одной фразой, задачи — списком из 5–7 пунктов
4. **Предметная область** — кто пользуется системой (3 роли), что вокруг чего организовано (студент → группа → направление)
5. **Архитектура** — схема «Angular ↔ NestJS ↔ PostgreSQL», модульный монолит, обоснование в одну фразу на пункт (почему не микросервисы / не Docker — коротко, подробности только если спросят)
6. **Модель данных** — упрощённая ER-диаграмма (5–7 ключевых сущностей, не все 30 таблиц)
7. **Ролевая модель** — таблица роль → что видит; схема permission + scope
8. **Табель посещаемости** — скриншот golden path: список группы с отметками, подсветка отсутствующих, диалог причины
9. **Валидация табеля** — скриншот «Не все студенты отмечены» / «✓ Все N отмечены»
10. **Импорт Excel** — скриншот мастера на шаге проверки (валидные/ошибки), подчеркнуть «весь файл, не только превью»
11. **Автоматический перевод курса** — скриншот предпросмотра с разбивкой по переходам
12. **Отчётность** — скриншот сводного отчёта или отчёта по группе
13. **Безопасность** — JWT + Argon2 + RBAC/scope + валидация входных данных, одним слайдом с иконками/схемой, не текстовой простынёй
14. **Тестирование** — цифры: 18 тестов (5 unit + 13 e2e), 8 найденных и исправленных реальных дефектов — назвать 1–2 самых показательных (идемпотентность перевода курса, скрытый частичный импорт)
15. **Результаты** — что реализовано (список модулей), что проверено, чего не хватает для промышленной эксплуатации (честно, коротко)
16. **Перспективы развития** — Docker, личный кабинет, уведомления, расширение тестов

## Принципы оформления

- На слайде с кодом/схемой — не больше одной мысли
- Скриншоты — из реально работающей системы (см. `docs/13-figures.md`), не мокапы
- Числа (18 тестов, 8 дефектов, 30 таблиц, 20 API-модулей) — считать по факту перед каждой защитой, не переносить бездумно из этого документа, если код успел измениться
