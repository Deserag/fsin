## Как получить свежие скриншоты

Скриншоты выше сделаны на конкретный момент разработки. Если функциональность изменится, актуальные скриншоты можно переснять тем же способом:

```bash
# backend и frontend должны быть запущены (см. 08-run-guide.md)
cd /tmp && npm init -y && npm install playwright && npx playwright install chromium
# затем — простой Playwright-скрипт с page.goto(...) + page.screenshot(...)
# на нужные экраны, залогинившись под demo-аккаунтом администратора
```
